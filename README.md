## ~/about

I build LLM systems that hold up in production: RAG pipelines, AI agents, and the MCP tool layers that let them actually get work done.

By day I'm at **Skala MRP**, wiring an agent layer into an enterprise ERP/MRP platform so people can ask their production plan questions in plain language. Before that I co-founded **Comcai**, an AI call-analytics startup that grew to 10k+ calls a month, and spent a summer at **Aktif Bank R&D** making RAG document search 3× faster.

Off the clock I write small, fast, self-hosted tools in **Rust** (my notes app idles at ~1.5 MB of RAM) and bend my Linux laptop until it behaves. Currently doing an MSc in Data Analytics at Altınbaş University, after a BSc in MIS and an Erasmus+ semester in A Coruña.
